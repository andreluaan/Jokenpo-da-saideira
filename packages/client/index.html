    Como jogar
    • WASD move. Clique em um adversário ou Tab para escolher o alvo.
    • 1 / 2 / 3: ✊ Pedra, ✋ Papel, ✌️ Tesoura. Sem símbolo, ataca; com símbolo, troca (custa foco).
    • Sendo atacado? Aperte um símbolo para responder: vira um duelo.
    • Os punhos batem no ritmo do JO… KEN… PÔ! Aperte Espaço no PÔ! para o PERFEITO. Cedo = BOM garantido; sem confirmar = FALHA.
    • F finta (parece uma troca), X/botão direito cancela, Shift investida.
    • Quem perde toma uma rasteira. Machucado? Na mesa amarela, aperte E para tomar uma gelada (+1 ❤). Se apanhar bebendo, derrama!
    • A vantagem do símbolo sempre vale mais que a execução.
