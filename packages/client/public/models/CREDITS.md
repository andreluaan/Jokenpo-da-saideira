# Créditos dos modelos 3D

Todos os modelos desta pasta são da **Kenney** (https://kenney.nl), licença **Creative Commons CC0 1.0**
(domínio público; uso comercial permitido; atribuição não obrigatória — mas fica aqui o agradecimento).

| Pasta | Pacote original |
|---|---|
| `chars/` | Mini Characters |
| `food/` | Food Kit |
| `furniture/` | Furniture Kit |
| `nature/` | Nature Kit |

Os originais completos (com o License.txt de cada pacote) ficam em `assets-src/` (fora do Git).
Cores, cabelos e acessórios dos personagens são modificados em tempo de execução pelo jogo.
